## 🛠️ Sobre o Projeto
O sistema simula uma plataforma de vendas para a loja "PC Mania", permitindo que o usuário interaja via terminal para escolher entre diferentes promoções de computadores, adicione os itens ao carrinho de compras e finalize o pedido visualizando um resumo completo com os dados do cliente, as configurações das máquinas e o valor total.

### Conceitos Aplicados:
* **Encapsulamento Estrito:** Atributos privados e uso restrito de getters/setters.
* **Composição e Agregação:** Relações estruturais entre `Computador`, `SistemaOperacional`, `HardwareBasico`, `MemoriaUSB` e `Cliente'.
* **Organização em Pacotes:** Estrutura modularizada seguindo as convenções da linguagem.
* **Métodos Estáticos:** Utilização de classes utilitárias para o processamento de pedidos.
